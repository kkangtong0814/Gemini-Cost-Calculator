# Gemini Cost Calculator (v1.1.0)

SillyTavern에서 Gemini API 사용 비용을 원화(KRW)와 달러(USD)로 간편하게 확인하고 관리할 수 있는 서드파티 확장입니다.

토큰이나 프롬프트 캐싱을 잘 모르는 일반 유저도 별도 설정 없이 바로 정확한 비용을 확인할 수 있도록 설계했습니다.

## 업데이트 로그

### v1.1.0
- **장기챗 최적화:** 토큰 계산 메모리 캐시 도입(반복 열기 즉시 계산), 장기 채팅 계산 중 안내 토스트, 실리태번 최대 컨텍스트(`maxContext`) 상한선 반영으로 장기챗 예상 금액 정확도 향상
- **모바일 반응형 & 터치 UX:** 좁은 모바일 화면(`<= 520px`) 전용 레이아웃 추가, 탭 가로 스크롤, 최근 호출 로그 터치 시 상세 토큰 내역 토스트 표시
- **다중 확장 동시성 보강:** 최근 로그 보관 한도 `40건 -> 100건` 확대, 메인 스트림 완료 대기(`pendingMainFetch`) 안전장치로 미세 타이밍 중복 집계 원천 차단

### v1.0.1
- 모달에서 추가·삭제한 커스텀 프리셋을 확장 설정 서랍 드롭다운에도 실시간 동기화
- 1,024토큰 미만 초단발·연결 테스트 호출을 실측 캐시율 평균에서 제외하고, 5분 초과 답장 간격으로 인한 자연 만료를 구분 안내
- 최근 API 호출 로그 각 행에 상세 툴팁(실측/추정, 캐시/일반 입력, 본문/생각 출력) 추가
- 키보드 `ESC` 키로 모달 닫기 지원 및 채팅창 버튼 주입 디바운스 최적화

### v1.0.0
- 정식 첫 배포 (멀티모델·독립 확장 추적, 고정 프롬프트·캐시 적중률 자동 맞춤, 커스텀 프리셋 추가·삭제, 예산 관리, 오류 확인 모달)

## 주요 기능

- **2026 최신 Gemini 모델 단가 프리셋 & 커스텀 프리셋 관리**
  - Gemini 4 Carbon / Argon (프로모션가·정상가 자동 분기), Hydrogen, Neon, 3.8 Flash, 3.5 Flash-Lite, 3.1 Pro Preview (200k 구간별 단가) 지원
  - `직접 입력 (Custom)`에서 원하는 단가 이름과 가격을 여러 개 추가·저장하고 삭제 가능 (비교표·드롭다운 자동 연동)
  - 추론(Thinking) 토큰은 출력 단가에 자동 합산
- **네트워크 자동 추적 (`window.fetch` 인터셉터)**
  - 메인 채팅은 물론, 요약·번역·독립 확장·외부 직접 API 호출까지 백그라운드에서 자동 감지 및 출처별 집계
  - API 실측 `usage` / `usageMetadata`를 우선 사용하고, 없을 때만 로컬 토크나이저로 추정
- **AI 호출 없는 즉시 계산 & 자동 맞춤**
  - 말풍선 하단 비용 배지 클릭, 말풍선 `...` 메뉴 동전 아이콘, 하단 옵션 메뉴, 확장 메뉴에서 즉시 실행
  - 고정 프롬프트(프리셋·캐릭터·상시 로어북·페르소나 또는 실측 역산) 및 추정 캐시 적중률(최근 실측 평균) 자동 맞춤
- **내돈내산 유저를 위한 지출 관리**
  - 일일·월간 예산 설정 및 80% / 100% 도달 경고 알림
  - 스와이프(리롤)·재생성 숨은 비용 누적 표시
  - 실측 프롬프트 캐시 적중률 모니터링, 최근 7일 일자별 지출, 로그 개별 삭제 및 JSON 백업/복원
  - 상단 우측 `오류 확인` 버튼으로 정상 상태 확인, 오류 제보 리포트 원클릭 복사 및 정상 동작 시 자동 해소

## 설치 방법

### 주소로 설치 (권장)
1. SillyTavern 상단 **확장(퍼즐 아이콘)** → **Install extension** 클릭
2. 아래 GitHub 주소를 붙여넣고 설치
   ```text
   https://github.com/kkangtong0814/Gemini-Cost-Calculator
   ```
3. SillyTavern 새로고침

## 개인정보 및 보안 안내

- **별도 AI API 호출 없음:** 채팅 비용 계산 및 고정 프롬프트 측정 기능은 AI API를 호출하지 않고 로컬에서만 계산합니다.
- **개인정보·API 키 미수집:** 사용자의 API 키, 개인정보, 채팅 내용은 외부 서버로 전송되거나 수집되지 않습니다.
- **로컬 저장:** 모든 지출 통계와 로그는 사용자 브라우저(`localStorage`)에만 저장되며, `오류 확인` 리포트에도 API 키나 채팅 내용은 포함되지 않습니다.
